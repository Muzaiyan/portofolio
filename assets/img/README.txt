Letakkan gambar Anda di folder ini dengan nama file berikut.
Jika sebuah file tidak ada, halaman menampilkan ilustrasi atau inisial sebagai gantinya.

foto-profil.jpg       Foto profil di bagian atas. Rasio 4:5 (potret), minimal 800 x 1000 px.
proyek-fiber.jpg      Foto dokumentasi proyek fiber optik. Rasio 4:3.
proyek-lan.jpg        Foto dokumentasi pembuatan kabel LAN. Rasio 4:3.
proyek-switch.jpg     Foto dokumentasi konfigurasi perangkat jaringan. Rasio 4:3.
sertifikat-bnsp.jpg   Foto atau pindaian sertifikat BNSP.

Ingin memakai nama file lain? Ubah isian "photo" dan "image" di js/data.js.
Gunakan format JPG atau WebP dan usahakan setiap file di bawah 500 KB agar halaman cepat dibuka.
